Array/List strengths:
- Easier to work with.
- Indexing capability, e.g., marks[2].
- Simple implementation when student marks are known beforehand.
- Reduced memory requirements.

Array/List weaknesses:
- Element shifting might be necessary upon insertion/deletion.
- Difficulty in resizing static arrays.

Strengths of linked list:
- Convenient addition of nodes.
- Dynamic size adjustment.
- Optimal insert/delete operations when the location is known.

Weaknesses of linked list:
- Lack of indexing.
- Need for sequential scanning during search.
- Additional memory usage since each node contains both data and pointers.
- More complex than an array/list.
